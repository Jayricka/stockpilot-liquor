# StockPilot Liquor

StockPilot Liquor is a mobile-first SaaS platform for licensed liquor stores.

It helps business owners manage:

- Products and categories
- Inventory
- Purchases
- Suppliers
- Sales
- Gross profit
- Stock movements
- Delivery orders
- Business-level data isolation
